# Rasputin support

Rasputin Desktop currently supports Windows x64 preview builds.

## Get help

- Read the [README](README.md) for installation and first-launch steps.
- Search [existing issues](https://github.com/Shingenn5/Rasputin/issues) before opening a new one.
- Use the bug-report form for crashes, installation failures, model-loading failures, or incorrect behavior.
- Use the feature-request form for product ideas.

Do not post API keys, access tokens, private prompts, model files, runtime databases, logs containing secrets, or personal workspace contents.

## Useful diagnostic details

Include the Rasputin version, Windows version, CPU, GPU and VRAM, model ID and GGUF quantization, exact error text, and reproducible steps. Redact usernames, paths, tokens, and private content.

Security vulnerabilities should follow [SECURITY.md](SECURITY.md), not public issues.
